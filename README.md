# CodeX

Проект CodeX — минимальный пример конфигурации и использования Jest для тестирования JavaScript/Node.js приложений.

Актуально на 2025-10-16 (UTC).

Текущее состояние
- Пример настроек тестирования с использованием Jest.

Требования
- Node.js v14+ (рекомендуется использовать актуальную LTS-версию)
- npm или yarn

Установка

```bash
npm install
```

Запуск тестов

```bash
npm test
```

Для запуска тестов с покрытием используйте:

```bash
npm test -- --coverage
```

Как внести изменения
- Создайте форк репозитория и откройте pull request.
- Для предложений и баг-репортов используйте Issues.
